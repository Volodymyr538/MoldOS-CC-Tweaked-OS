# Разработка приложений для MoldOS

Это руководство для тех, кто хочет написать своё приложение для MoldOS —
операционной системы для компьютеров CC: Tweaked в Minecraft.

## Быстрый старт

1. Возьми пример минимального приложения в конце этого документа за основу
2. Добавь блок сертификата в первых строках файла со своими данными
3. Напиши код приложения ниже сертификата
4. Помести готовый `.lua` файл в папку `/os/apps/` на компьютере
   (вручную через файловый менеджер, либо через `wget`)

Приложение сразу появится в главном меню MoldOS на вкладке **Apps**.

## Сертификат приложения

Каждое приложение MoldOS должно начинаться с блока сертификата — это
обычный текстовый комментарий в самом начале файла (в первых 10 строках),
который MoldOS читает при построении списка приложений:

```lua
-- MOLDCERT_NAME    = "Моё приложение"
-- MOLDCERT_VERSION = "1.0"
-- MOLDCERT_AUTHOR  = "ТвоёИмя"
-- MOLDCERT_KEY     = "12345"
```

### Важно понимать про сертификат

Сертификат — это **просто метаданные для красивого отображения**, а не
средство защиты или система лицензирования. MoldOS не проверяет
подлинность ключа, не блокирует запуск приложений без сертификата и не
ограничивает, что может делать код приложения. Это просто способ:

- Показать красивое название приложения в меню вместо имени файла
- Дать понять пользователю, кто автор и какая версия установлена

Если сертификат отсутствует или неполный, MoldOS просто покажет имя
файла вместо `MOLDCERT_NAME` — приложение всё равно запустится.

### Правила оформления сертификата

- Все 4 строки должны находиться в первых **10 строках** файла
- Формат строго такой: `MOLDCERT_ПОЛЕ = "значение"` (с кавычками)
- `MOLDCERT_KEY` — любые 5 цифр на твоё усмотрение (MoldOS их не
  проверяет и не использует — это только для твоего собственного учёта
  версий, если понадобится)

## API MoldOS для приложений (MoldAPI)

MoldOS передаёт каждому запущенному приложению глобальную таблицу
`MoldAPI` с несколькими полезными функциями:

```lua
-- Отправить системное уведомление (появится звёздочка в углу меню)
MoldAPI.notify("Что-то произошло!")

-- Получить текущую тему оформления
local theme = MoldAPI.getTheme()
-- theme.name   -- название темы, например "Ocean"
-- theme.bg     -- цвет фона (colors.xxx)
-- theme.fg     -- цвет текста
-- theme.accent -- акцентный цвет (для заголовков, кнопок и т.д.)

-- Получить имя текущего вошедшего пользователя
local user = MoldAPI.getCurrentUser()
```

### Проверяй наличие MoldAPI

Приложение может быть запущено не только из MoldOS, но и напрямую из
обычного CraftOS-шелла — тогда `MoldAPI` не будет существовать. Всегда
проверяй его перед использованием:

```lua
if MoldAPI then
    MoldAPI.notify("Привет от моего приложения!")
end
```

## Как писать код приложения

Всё, что идёт **после** блока сертификата — обычный код на Lua. Никакой
особой песочницы нет: работают все стандартные API CC: Tweaked (`term`,
`fs`, `os`, `colors`, `peripheral`, `rednet` и так далее) точно так же,
как в любой другой программе для CraftOS.

MoldOS запускает приложения через обычный `shell.run(путь)`, поэтому
приложение — это просто файл `.lua`, который выполняется от начала до
конца, как любая программа CraftOS.

### Рекомендуемый стиль (не обязателен, но желателен)

Чтобы приложение органично смотрелось рядом со встроенными:

- **Управление мышью** — вся навигация должна быть кликабельной.
  Клавиатуру используй только там, где реально нужен ввод текста
  (например, название файла, сообщение в чат)
- **Чёрный фон, белый текст по умолчанию** — так оформлены все
  системные экраны
- **Кнопка выхода** — всегда должен быть понятный способ вернуться в
  главное меню MoldOS (обычно кнопка `[ Quit ]` внизу экрана)
- **Обработка кликов через `os.pullEvent("mouse_click")`** — событие
  возвращает `button, x, y`, где `button` равен `1` для левой кнопки
  мыши и `2` для правой

### Пример обработки кликов

```lua
local _, button, x, y = os.pullEvent("mouse_click")

if y == 5 then
    if x >= 1 and x <= 10 then
        -- клик по кнопке в этой области
    end
end
```

## Проверка приложения перед публикацией

В MoldOS встроен антивирус-сканер (`apps/antivirus.lua`), который
проверяет `.lua` файлы на подозрительные паттерны — например, попытки
удалить системные файлы, отформатировать диск или отправить данные во
внешнюю сеть без ведома пользователя.

Перед тем как делиться своим приложением с другими, рекомендуется
проверить его через **Antivirus → Scan a File** прямо в системе — это
не только вопрос доверия, но и способ убедиться, что твой код случайно
не выглядит подозрительно (например, если ты используешь `http.post`
для чего-то легитимного, лучше знать, что сканер это отметит, и что
это ожидаемо).

Учти: это эвристический сканер по паттернам, а не полноценный анализ
кода — он не гарантирует, что приложение безопасно на 100%, и может
как пропустить реальную угрозу, так и ложно сработать на безобидный код.

## Куда класть готовые приложения

Официальные приложения MoldOS скачиваются автоматически через
`installer.lua` и команду **Install App** из списка `APP_REGISTRY`
в `os/startup.lua`. Если ты хочешь, чтобы твоё приложение стало частью
официального реестра — свяжись с автором проекта или предложи изменения
через GitHub.

Для личного использования или распространения среди друзей достаточно
просто передать файл `.lua` и попросить положить его в `/os/apps/`
вручную, либо через `wget` с любого источника, который тебе удобен.

## Пример минимального приложения

```lua
-- MOLDCERT_NAME    = "Привет, мир"
-- MOLDCERT_VERSION = "1.0"
-- MOLDCERT_AUTHOR  = "Тест"
-- MOLDCERT_KEY     = "00001"

local function clear()
    term.setBackgroundColor(colors.black)
    term.setTextColor(colors.white)
    term.clear()
    term.setCursorPos(1, 1)
end

clear()
term.write("Привет, мир!")
term.setCursorPos(1, 3)
term.write("[ Выход ]")

while true do
    local _, _, x, y = os.pullEvent("mouse_click")
    if y == 3 and x >= 1 and x <= 9 then
        break
    end
end

clear()
```

Сохрани это как, например, `hello.lua`, положи в `/os/apps/` — и
приложение "Привет, мир" появится в меню MoldOS.
